# User Story Mapping - Kanban-Rust

## 📋 目的

このUSMは、ユーザーがKanban-Rustをどのように使用するかを理解し、優先順位付けされた機能開発を計画するためのものです。

---

## 👥 ユーザーペルソナ

### ペルソナ1: 個人ユーザー（田中健一 - フリーランスデザイナー）
- **年齢**: 32歳
- **職業**: フリーランスUI/UXデザイナー
- **技術レベル**: 中〜高
- **目標**: 複数のクライアントプロジェクトを効率的に管理し、期限を守る
- **課題**:
  - オンラインツールはプライバシーが心配
  - 複雑すぎるツールは学習コストが高い
  - 美しくないUIはモチベーションが下がる
- **利用シーン**:
  - 朝のタスク整理（20分）
  - クライアント打ち合わせ前の確認（5分）
  - 夜の振り返り（10分）

### ペルソナ2: 小規模チームリーダー（佐藤美咲 - スタートアップPM）
- **年齢**: 28歳
- **職業**: プロダクトマネージャー
- **チームサイズ**: 5人（エンジニア3人、デザイナー1人、自分）
- **技術レベル**: 中
- **目標**: チームの進捗を可視化し、ボトルネックを早期発見
- **課題**:
  - Jiraは重すぎる
  - Trelloは視覚的にわかりにくい
  - チームメンバーのタスク負荷が見えない
- **利用シーン**:
  - デイリースタンドアップ前の準備（10分）
  - タスクアサイン（随時）
  - スプリント振り返り（週1回、30分）

### ペルソナ3: エンタープライズユーザー（山田太郎 - 大企業プロジェクトマネージャー）
- **年齢**: 42歳
- **職業**: 大企業のITプロジェクトマネージャー
- **チームサイズ**: 20-50人
- **技術レベル**: 中〜低
- **目標**: 会社のSharePoint環境と統合し、セキュリティ要件を満たしながらチーム管理
- **課題**:
  - 会社の情報システムポリシーに準拠する必要がある
  - 外部SaaSは使えない
  - メンバーのITリテラシーにばらつきがある
- **利用シーン**:
  - 朝会前の全体確認（15分）
  - 週次レポート作成（30分）
  - 上層部への進捗報告（月1回）

## 1️⃣ アクティビティ: タスクを管理する

### Walking Skeleton

| タスク | ペルソナ | 頻度 |
|--------|---------|------|
| タスクを作成する | 全員 | 毎日 |
| タスクを編集する | 全員 | 毎日 |
| タスクを削除する | 全員 | 週数回 |
| タスクを完了にする | 全員 | 毎日 |

### ユーザーストーリー

#### MVP（実装済み ✅）
- ✅ **As a ユーザー**, I want to タスクを素早く追加できる, So that アイデアを逃さない
  - タイトル入力 + Enter で即座に作成
  - デフォルトで「未着手」列に追加

- ✅ **As a ユーザー**, I want to タスクをクリックして編集できる, So that 詳細情報を追加できる
  - タイトル、説明、優先度、期限、担当者、タグを編集
  - モーダルダイアログで編集

- ✅ **As a ユーザー**, I want to タスクを削除できる, So that 不要なタスクを整理できる
  - 削除ボタンでタスク削除
  - 確認ダイアログ表示（Phase 4で実装）

#### Phase 2（価値を高める）
- ✅ **As a ユーザー**, I want to 繰り返しタスクを設定できる, So that 定期作業を自動化できる
  - 毎日/毎週/毎月/カスタムパターン
  - 完了時に次のタスクを自動生成

- ⏳ **As a ユーザー**, I want to タスクを複製できる, So that 似たタスクを素早く作成できる
  - 右クリックメニューから複製（Phase 4.3で実装予定）
  - タイトルに「(コピー)」を追加

- ⏳ **As a ユーザー**, I want to タスクにサブタスクを追加できる, So that 大きなタスクを分解できる
  - チェックリスト形式のサブタスク
  - 進捗率の自動計算（Phase 7）

#### Phase 3+（Nice to have）
- ⏳ **As a ユーザー**, I want to タスクにファイルを添付できる, So that 関連資料を一元管理できる
  - ローカルファイル添付（Phase 7）
  - SharePoint連携時はSharePointに保存（Phase 5）

- ⏳ **As a ユーザー**, I want to タスクにコメントを追加できる, So that 作業履歴を記録できる
  - コメント追加・編集・削除
  - タイムスタンプ表示（Phase 7）

## 2️⃣ アクティビティ: タスクを整理する

### Walking Skeleton

| タスク | ペルソナ | 頻度 |
|--------|---------|------|
| タスクを列間で移動する | 全員 | 毎日 |
| タスクを検索する | 全員 | 週数回 |
| タスクをフィルタリングする | チームリーダー | 毎日 |
| タスクをソートする | 全員 | 週数回 |

### ユーザーストーリー

#### MVP（実装済み ✅）
- ✅ **As a ユーザー**, I want to タスクをドラッグ&ドロップで移動できる, So that ステータスを直感的に変更できる
  - 列間のD&D
  - 列内の並び替え
  - スムーズなアニメーション

- ✅ **As a ユーザー**, I want to タスクを検索できる, So that 目的のタスクを素早く見つけられる
  - タイトル・説明の全文検索
  - リアルタイム検索結果表示

- ✅ **As a ユーザー**, I want to タスクをフィルタリングできる, So that 特定の条件でタスクを絞り込める
  - タグ、担当者、優先度でフィルタリング
  - 複合フィルター対応

#### Phase 2（価値を高める）
- ⏳ **As a ユーザー**, I want to カスタム列を追加できる, So that 自分のワークフローに合わせられる
  - 列の追加・編集・削除（実装済み ✅）
  - 列の色変更（実装済み ✅）
  - 列の並べ替え（Phase 3.0.1で実装予定 ⏳）

- ⏳ **As a ユーザー**, I want to 保存済みフィルターを使える, So that よく使う条件を再利用できる
  - フィルター条件を名前付きで保存
  - ワンクリックで適用（Phase 6）

- ⏳ **As a ユーザー**, I want to タスクをグループ化できる, So that 関連タスクをまとめて見られる
  - 担当者別、タグ別、期限別グループ化
  - スイムレーン表示（Phase 7）

#### Phase 3+（Nice to have）
- ⏳ **As a ユーザー**, I want to タスクの依存関係を設定できる, So that 作業順序を明確にできる
  - ブロッカータスクの設定
  - 依存関係の可視化（Phase 7）

- ⏳ **As a ユーザー**, I want to スマート検索を使える, So that 自然言語で検索できる
  - 「今週期限」「山田さん担当」等の自然言語クエリ
  - コマンドパレット統合（Phase 7）

## 3️⃣ アクティビティ: 進捗を可視化する

### Walking Skeleton

| タスク | ペルソナ | 頻度 |
|--------|---------|------|
| カンバンボードで進捗を見る | 全員 | 毎日 |
| リストビューで一覧を見る | 全員 | 週数回 |
| 期限を確認する | 全員 | 毎日 |
| 優先度を確認する | 全員 | 毎日 |

### ユーザーストーリー

#### MVP（実装済み ✅）
- ✅ **As a ユーザー**, I want to カンバンボードでタスクを可視化できる, So that 全体の流れを把握できる
  - 3列デフォルト（未着手/進行中/完了）
  - カラムごとのタスク数表示
  - カラーコーディング

- ✅ **As a ユーザー**, I want to リストビューでタスクを表示できる, So that 詳細を一覧で確認できる
  - ソート可能なテーブル表示
  - 全フィールド表示
  - スクロール対応（修正済み ✅）

- ✅ **As a ユーザー**, I want to 期限が視覚的にわかる, So that 緊急度を直感的に判断できる
  - 期限切れ（赤）、今日（オレンジ）、近日（黄）
  - カレンダー日付表示

- ✅ **As a ユーザー**, I want to 優先度が視覚的にわかる, So that 重要度を直感的に判断できる
  - 低（緑）、中（黄）、高（オレンジ）、緊急（赤）
  - ラベル表示

#### Phase 2（価値を高める）
- ⏳ **As a ユーザー**, I want to カレンダービューで期限を確認できる, So that スケジュール全体を把握できる
  - 月次/週次/日次ビュー
  - 期限ベースの表示（Phase 7）

- ⏳ **As a ユーザー**, I want to ダッシュボードで統計を見られる, So that 生産性を測定できる
  - 完了率、進行中タスク数、期限切れ数
  - グラフ表示（Phase 6）

- ⏳ **As a ユーザー**, I want to タイムラインビューで流れを見られる, So that プロジェクト全体を俯瞰できる
  - ガントチャート風表示
  - 依存関係の可視化（Phase 7）

#### Phase 3+（Nice to have）
- ⏳ **As a ユーザー**, I want to レポートを生成できる, So that 上司に報告できる
  - 週次/月次レポート
  - PDFエクスポート（Phase 6）

- ⏳ **As a ユーザー**, I want to バーンダウンチャートを見られる, So that スプリント進捗を追跡できる
  - 理想ライン vs 実績
  - スプリント機能（Phase 7）

## 4️⃣ アクティビティ: チームで協働する

### Walking Skeleton

| タスク | ペルソナ | 頻度 |
|--------|---------|------|
| メンバーを追加する | チームリーダー | 週1回 |
| タスクをアサインする | チームリーダー | 毎日 |
| メンバーのタスクを確認する | チームリーダー | 毎日 |
| 通知を受け取る | 全員 | 毎日 |

### ユーザーストーリー

#### MVP（実装済み ✅）
- ✅ **As a チームリーダー**, I want to メンバーを追加できる, So that チームメンバーを管理できる
  - メンバー名と色を設定
  - アクティブ/非アクティブ管理

- ✅ **As a チームリーダー**, I want to タスクをメンバーにアサインできる, So that 責任を明確にできる
  - タスク編集時に担当者選択
  - 複数担当者対応

- ✅ **As a ユーザー**, I want to 自分のタスクをフィルタリングできる, So that 自分の作業に集中できる
  - 担当者フィルター
  - 「自分のタスク」ショートカット（Phase 4で実装予定）

#### Phase 2（価値を高める）
- ⏳ **As a ユーザー**, I want to 期限通知を受け取れる, So that タスクを忘れない
  - デスクトップ通知（実装済み ✅）
  - カスタマイズ可能な通知タイミング（Phase 7）

- ⏳ **As a エンタープライズユーザー**, I want to SharePointと同期できる, So that 会社のデータポリシーに準拠できる
  - 手動同期（Phase 5）
  - 自動同期（Phase 6）
  - リアルタイム同期（Phase 7検討）

- ⏳ **As a チームリーダー**, I want to メンバーの負荷を可視化できる, So that タスク配分を最適化できる
  - メンバー別タスク数
  - 負荷グラフ（Phase 6）

#### Phase 3+（Nice to have）
- ⏳ **As a ユーザー**, I want to タスクでコミュニケーションできる, So that 情報共有が楽になる
  - タスクコメント
  - @メンション（Phase 7）

- ⏳ **As a エンタープライズユーザー**, I want to 権限管理ができる, So that データアクセスを制御できる
  - 閲覧/編集/管理権限
  - ボードごとの権限設定（Phase 7）

- ⏳ **As a チームリーダー**, I want to タスクの履歴を確認できる, So that 変更追跡できる
  - 変更履歴ログ
  - 差分表示（Phase 7）

## 5️⃣ アクティビティ: システムを設定する

### Walking Skeleton

| タスク | ペルソナ | 頻度 |
|--------|---------|------|
| テーマを変更する | 全員 | 初回のみ |
| 通知設定を変更する | 全員 | 初回 + 随時 |
| データをエクスポートする | 個人ユーザー | 月1回 |
| バックアップする | エンタープライズ | 週1回 |

### ユーザーストーリー

#### MVP（実装済み ✅）
- ✅ **As a ユーザー**, I want to データがローカルに保存される, So that オフラインで使える
  - localStorage自動保存
  - Tauri file storage（実装済み、未統合）

#### Phase 2（価値を高める）
- ⏳ **As a ユーザー**, I want to ダークモード/ライトモードを切り替えられる, So that 目に優しい
  - システム設定に従う
  - 手動切り替え（Phase 4検討）

- ⏳ **As a ユーザー**, I want to データをエクスポートできる, So that バックアップできる
  - JSON形式エクスポート
  - CSV形式エクスポート（Phase 6）

- ⏳ **As a ユーザー**, I want to データをインポートできる, So that 移行できる
  - JSON形式インポート
  - 他ツールからのインポート（Phase 7）

#### Phase 3+（Nice to have）
- ⏳ **As a ユーザー**, I want to キーボードショートカットをカスタマイズできる, So that 自分の好みに合わせられる
  - ショートカット一覧表示
  - カスタムキーバインド（Phase 7）

- ⏳ **As a エンタープライズユーザー**, I want to 自動バックアップを設定できる, So that データ損失を防げる
  - SharePoint自動バックアップ
  - スケジュール設定（Phase 6）

## 🎯 優先順位マトリクス

### 高価値 × 低工数（すぐやる）
- ✅ 列の並べ替え（Phase 3.0.1）- 4時間
- ⏳ タスク複製（Phase 4.3）- 2時間
- ⏳ 「自分のタスク」フィルター - 1時間
- ⏳ ダークモード切り替え - 3時間

### 高価値 × 高工数（計画的に実施）
- ⏳ Apple風UIデザイン（Phase 4）- 41-52時間
- ⏳ SharePoint連携（Phase 5）- 34-42時間
- ⏳ ダッシュボード（Phase 6）- 12-15時間

### 低価値 × 低工数（余裕があればやる）
- ⏳ タスクカラーカスタマイズ - 2時間
- ⏳ ショートカット一覧表示 - 2時間

### 低価値 × 高工数（やらない）
- ⏳ プラグインシステム - 30時間+
- ⏳ カスタムフィールド - 20時間+

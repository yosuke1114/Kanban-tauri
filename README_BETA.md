# Kanban Board - ベータ版 v0.1.0-beta.1

Tauri + React + TypeScriptで構築された、ビジネスプロフェッショナル向けカンバンボードアプリケーションです。

## 📥 インストール方法

### macOS

1. [リリースページ](https://github.com/yosuke1114/Kanban-tauri/releases/tag/v0.1.0-beta.1)から`kanban-rust_0.1.0-beta.1_x64.dmg`をダウンロード
2. DMGファイルをダブルクリックして開く
3. Kanban Boardアプリを「Applications」フォルダにドラッグ
4. Applicationフォルダから起動

**注意**: 初回起動時に「開発元が未確認」の警告が表示される場合：
- 右クリック（またはControl+クリック）→「開く」を選択
- 「開く」をクリック

### Windows

1. [リリースページ](https://github.com/yosuke1114/Kanban-tauri/releases/tag/v0.1.0-beta.1)から`kanban-rust_0.1.0-beta.1_x64.msi`をダウンロード
2. MSIファイルをダブルクリック
3. インストーラーの指示に従ってインストール
4. スタートメニューまたはデスクトップから起動

### Linux (Debian/Ubuntu)

```bash
# .debファイルをダウンロード
wget https://github.com/yosuke1114/Kanban-tauri/releases/download/v0.1.0-beta.1/kanban-rust_0.1.0-beta.1_amd64.deb

# インストール
sudo dpkg -i kanban-rust_0.1.0-beta.1_amd64.deb

# 依存関係の解決（エラーが出た場合）
sudo apt-get install -f
```

### Linux (AppImage)

```bash
# AppImageをダウンロード
wget https://github.com/yosuke1114/Kanban-tauri/releases/download/v0.1.0-beta.1/kanban-rust_0.1.0-beta.1_amd64.AppImage

# 実行権限を付与
chmod +x kanban-rust_0.1.0-beta.1_amd64.AppImage

# 実行
./kanban-rust_0.1.0-beta.1_amd64.AppImage
```

## 📖 基本的な使い方

### 1. タスクを作成する

1. ヘッダーの「タスク追加」ボタンをクリック
2. タスクタイトルを入力
3. 「追加」をクリック（または`Enter`）
4. タスクをクリックして詳細を編集

### 2. タスクを移動する

- **ドラッグ&ドロップ**: タスクをドラッグして別の列に移動
- **タスク編集**: タスクをクリック→列を選択

### 3. データをバックアップする

1. ヘッダーの「管理」→「データ保存設定」
2. 「エクスポート」ボタンをクリック
3. 保存先を選択してファイルを保存

### 4. マルチボードを使う

1. ヘッダーのボード名横のアイコンをクリック
2. 「新規ボード作成」で新しいプロジェクトボードを追加
3. ドロップダウンでボードを切り替え
